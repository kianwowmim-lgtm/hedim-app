# هدیم — نصب و اجرا

## اجرا روی کامپیوتر
فایل `index.html` را با مرورگر باز کنید. به اینترنت یا سرور نیاز ندارد.

## نصب روی گوشی (بدون فروشگاه)
۱. این پوشه را روی یک میزبان ایمن (HTTPS) مثل Netlify Drop، GitHub Pages یا هر هاست استاتیک قرار دهید.
۲. آدرس را در Chrome (اندروید) یا Safari (آیفون) باز کنید.
۳. منوی مرورگر ← «افزودن به صفحه اصلی» را بزنید.
۴. از این پس «هدیم» مثل یک اپ با آیکون خودش باز می‌شود.

## تبدیل به فایل APK / پکیج فروشگاه
- **PWABuilder** (pwabuilder.com): آدرس HTTPS را وارد کنید و پکیج اندروید یا iOS بگیرید.
- **Capacitor**: این پوشه را به‌عنوان `www` در پروژه Capacitor قرار دهید و `npx cap add android` را اجرا کنید.

## ذخیره‌سازی داده‌ها
- داده‌ها داخل مرورگر همان دستگاه ذخیره می‌شوند و با هر تغییر خودکار ذخیره می‌شوند.
- برای انتقال به دستگاه دیگر یا پشتیبان‌گیری، از تب «گزارش» متن پشتیبان را کپی کنید و در دستگاه جدید بازیابی کنید.
- اگر مرورگر را پاک کنید، داده‌ها از بین می‌روند؛ پشتیبان منظم بگیرید.

## فونت
فونت «ایران خوارزمی» در `index.html` قرار دارد. طبق `fonts/FontLicense.txt` و `fonts/شرایط-استفاده.pdf`، کد لایسنس ۵ رقمی باید در کامنت ابتدای `index.html` (متغیر LICENSE_CODE) درج شود. این فایل‌ها را کنار فونت نگه دارید.

## محدودیت‌ها
ویرایش تراکنش، تاریخ شمسی در گزارش‌ها به شکل کامل، چند حساب و چند ارز، فاکتور و دفتر کل هنوز پیاده‌سازی نشده‌اند.
